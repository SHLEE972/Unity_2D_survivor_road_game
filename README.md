# Survivor Road

**Survivor Road**는 플레이어가 몰려오는 적을 처치하며 성장하고, 여러 경로를 선택해 최종 보스에 도전하는 2D 탑다운 생존 액션 게임입니다.

## 게임 소개

플레이어는 WASD로 캐릭터를 움직이고 자동으로 발사되는 검기를 이용해 적을 처치해야 합니다.  
전투에서 살아남으면 보상을 선택하고, 지도에서 상점, 휴식, 랜덤 사건 또는 다음 전투로 이동할 수 있습니다.

최종 목표는 캐릭터를 강화하면서 모든 전투를 통과하고 마지막 보스를 처치하는 것입니다.

## 주요 기능

- WASD 기반 2D 캐릭터 이동
- 가까운 적을 자동으로 공격하는 검기 시스템
- 일반, 원거리, 엘리트 적 등장
- 돌진과 부하 소환 패턴을 사용하는 보스
- 전투 단계에 따라 증가하는 난이도
- 적 처치 시 골드 획득
- 전투 중 등장하는 보물상자
- 전투 종료 후 능력치 보상 선택
- 골드로 유물을 구매하는 상점
- HP를 회복할 수 있는 휴식 장소
- 긍정 및 부정 결과가 발생하는 랜덤 사건
- 플레이어 HP, 골드, 점수, 타이머 UI
- 타이틀, 전투, 지도, 상점, 휴식, 사건, 게임 오버 씬 구성
- WebGL 빌드 및 웹 브라우저 플레이 지원

## 조작법

| 키 | 동작 |
|---|---|
| `W` | 위로 이동 |
| `S` | 아래로 이동 |
| `A` | 왼쪽으로 이동 |
| `D` | 오른쪽으로 이동 |
| 마우스 클릭 | 버튼 및 보상 선택 |
| 공격 | 일정 시간마다 자동 발동 |

## 게임 진행

```text
타이틀
→ 전투
→ 보상 선택
→ 지도 경로 선택
→ 상점 / 휴식 / 랜덤 사건 / 다음 전투
→ 캐릭터 강화
→ 최종 보스 전투
→ 게임 클리어
